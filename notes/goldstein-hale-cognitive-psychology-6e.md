# Goldstein & Hale (2026) — Cognitive Psychology, 6th edition

Official Cengage survey text. This file is a **study stub and bibliographic record**, not a replacement for the book. Do not paste chapter text here.

## One-sentence thesis

Cognitive psychology is an experimental science of mind whose classic demonstrations and current findings can be taught through the same processes students already use in daily life.

## Who should read it

- First undergraduate course in cognition
- Self-learners who want figures, demonstrations, and a narrative ramp before primary papers
- Readers who will later move to Eysenck & Keane (denser handbook) or Gazzaniga (neuroscience)

## Study method for this book

After each chapter:

1. Name the **process** (e.g., encoding specificity) in one sentence.
2. Name the **demo or experiment** the chapter uses.
3. Write one **everyday example** that is *yours*, not the book's.
4. Open the matching file under `topics/` and add a link to this note if the chapter is a core source.
5. Put constructs — not page-long summaries — into Anki.
