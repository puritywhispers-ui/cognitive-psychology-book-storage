# Memory

Memory is not a single store. Cognitive psychology treats it as systems and processes: encoding, storage, retrieval, plus reconstruction and error.

## Systems map (working vocabulary)

```text
Sensory memory (iconic / echoic)
        |
Working memory (central executive, phonological loop,
                visuospatial sketchpad, episodic buffer)
        |
Long-term memory
  ├─ explicit / declarative
  │    ├─ episodic (events, autonoetic awareness)
  │    └─ semantic (facts, concepts)
  └─ implicit / nondeclarative
       ├─ procedural
       ├─ priming
       └─ conditioning / some habit systems
```

This map is a teaching scaffold, not a settled ontology. Boundaries (especially working memory vs. attention, episodic vs. semantic) are actively debated.

## Process ideas that changed the field

- **Levels of processing** (Craik & Lockhart, 1972): depth of encoding predicts later access better than store-to-store transfer alone.
- **Encoding specificity** (Tulving & Thomson): retrieval succeeds when cues match the encoded trace.
- **Transfer-appropriate processing**: match the processes at test to the processes at study.
- **Reconstruction**: Bartlett; Loftus misinformation; DRM false memory.
- **Seven sins** (Schacter): transience, absent-mindedness, blocking, misattribution, suggestibility, bias, persistence — errors as byproducts of adaptive design.

## Working memory, specifically

Baddeley & Hitch (1974) replaced a single short-term store with a multi-component workspace. Later additions:

- episodic buffer (binding across codes)
- debates with Cowan's embedded-processes model (focus of attention + activated LTM)
- Engle's executive-attention account of WM capacity / WMC as control

## Books

- Baddeley, Eysenck & Anderson — *Memory* (textbook)
- Baddeley — *Working Memory, Thought, and Action*
- Schacter — *Searching for Memory*; *The Seven Sins of Memory*
- Tulving — *Elements of Episodic Memory*
- Bartlett — *Remembering* (1932)
- Loftus work via papers rather than a single textbook

## Study practice that actually follows the science

- Retrieval practice > rereading
- Spaced repetition > massed cramming
- Interleaving related problem types
- Elaborative interrogation and self-explanation
- Sleep as consolidation support, not a mnemonic trick
