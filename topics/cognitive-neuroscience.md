# Cognitive neuroscience bridge

Use neuroscience as a constraint on cognitive theory, not as a replacement for behavioral evidence.

## What the methods are good for

| Method | Strength | Limit |
| --- | --- | --- |
| Lesion / neuropsychology | Necessity arguments | Specificity, reorganization, small N |
| fMRI / PET | Spatial localization of *relative* activity | Not a process model; reverse inference risk |
| EEG / MEG / ERPs | Millisecond timing | Source localization harder |
| TMS / tES | Causal perturbation | Spatial blur, state dependence |
| Single-unit / ECoG | Mechanistic grain | Rare in healthy humans |
| Computational models + neural data | Links levels | Extra free parameters |

## Reverse-inference discipline

"This area lit up, therefore this cognitive process happened" is invalid unless you have established selectivity. Store Poldrack's warnings next to any imaging claim you write down.

## Productive pairings

- Working memory → prefrontal / frontoparietal control literature, but keep the cognitive model first
- Episodic memory → hippocampus and reconsolidation debates
- Face perception → FFA plus expertise and network accounts
- Language → classic Broca/Wernicke maps are teaching cartoons; use dual-stream models
