# Popular, crossover, and applied books

Useful for intuition and communication. They are not substitutes for a methods-aware textbook when you need to evaluate evidence.

| Book | Author | Why keep it |
| --- | --- | --- |
| *Thinking, Fast and Slow* | Daniel Kahneman | Dual-process vocabulary now used across medicine, policy, product |
| *Influence* | Robert Cialdini | Compliance principles; social-cognitive applications |
| *Nudge* | Thaler & Sunstein | Choice architecture |
| *The Language Instinct* | Steven Pinker | Public argument for specialized language machinery |
| *How the Mind Works* | Steven Pinker | Evolutionary-cognitive synthesis; controversial in places |
| *The Seven Sins of Memory* | Daniel Schacter | Taxonomy of forgetting and distortion |
| *Pieces of Light* / memory titles | Charles Fernyhough | Autobiographical memory as reconstruction |
| *The Scientist in the Crib* | Gopnik, Meltzoff & Kuhl | Developmental cognition for non-specialists |
| *Predictably Irrational* | Dan Ariely | Behavioral experiments in everyday framing |
| *The Mind's New Science* | Howard Gardner | History |
| *Incognito* | David Eagleman | Popular cognitive neuroscience |
| *Livewired* | David Eagleman | Plasticity |
| *Why We Remember* | Charan Ranganath | Contemporary memory systems for general readers |

## How to read popular books in this field

1. Extract the *named effect* or *named system* (System 1, working memory, schema, phonological loop).
2. Find the original paper in `catalog/papers.md`.
3. Check a recent textbook chapter for replications, moderators, and failed generalizations.
4. Write a short note: what survives, what was overclaimed.
